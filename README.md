# Shopping List App

A simple Android application built with **Kotlin** and **Jetpack Compose**.  
This was my first Kotlin project, created to learn the basics of UI, state management, and local data storage.

### Features
- Add items to the shopping list
- Mark items as purchased
- Swipe to delete single items
- Clear the entire list with confirmation
- Persistent storage using **DataStore**
- Light & dark theme support
